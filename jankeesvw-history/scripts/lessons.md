
## 1. Lessons (read this first)

### 1.1 What he fixes, in order of frequency
1. **Layout/state/logic edge cases in QML panels and bar widgets** (largest group, mostly `runtime:logic-error`, `in-use:stale-or-wrong-display`, `qml:binding-or-layout`): a binding evaluated before its source exists (`store.iconFor` on a singleton that is not ready, `item.kind` on a null delegate, `.length` on an undefined flag list), input accepted before saved state is restored (omasweeper `handleKey` before `stateLoaded`), a flash at login because a guard counted one file read and not the second (workspace-name d648de3), per-monitor state read from the global focus (workspace-name 38e9c49), a fixed list of five workspaces. None of these has a lexical signature; they are visible only by reading the binding and asking "what is undefined or stale at first paint, on a second monitor, on an empty list?".
2. **Untrusted data and secrets handled through the wrong channel** (security kind, the second large group; almost all in 2026-08-19..09-06 when he hardened every plugin that talks to a remote service or a local daemon): secret in argv (`curl -H "X-API-KEY: $KEY"`, `jq --arg rt "$REFRESH"`, a workspace name in `Process.command`), secret in the environment (`export UNIFI_WATCH_KEY`), predictable or shared cache paths (`/tmp` fallback, `mkdir` with default mode, cache dir mode checked but files left from an older install), check-then-open races (`path` command that validates then returns a name; `write_private` between `mktemp` and `mv`), rich-text rendering of external strings (workspace name, camera name, tooltip text), unbounded reads (`resp.read()`, `hyprctl` output into a shell variable, a whole folder scanned before row caps), certificates not verified or auto-pinned, `pip install` without hashes, option injection (`exec mpv ... "$url"` with no `--`), bash arithmetic over a jq value (`$(( $(now) + expires_in ))` where `expires_in` is `a[$(cmd)]`).
3. **Shell-compat breaks** (two dated events, 23 fix commits): 10-09 Qt 6.12 adds a `Color` singleton to QtQuick, so `Color.accent` next to `import qs.Commons` resolves to Qt's type and every colour comes out undefined/black (17 repos fixed on that one day, always the same two-file commit: `import qs.Commons as Commons`, `Commons.Color.*`, patch version bump); 10-13 the new Omarchy shell scales whatever a widget hands over as `iconComponent` down to one bar-icon size, so counts, badges and countdown text shrink to a smudge (6 repos: drop `iconComponent`/`opticalSize`, set `hasVisualContent: true` and put the content directly in the button).
4. **Process lifecycle** (8-10 commits): stop a running child (`exec` instead of command substitution so a signal reaches it), reset `stdinEnabled` so the second run does not wait forever, launch `wl-copy` so it outlives the app, wait for plugin discovery before enabling, count a timed-out enable as done when the widget is already on the bar.
5. **Format and edge-of-protocol bugs in helper scripts** (gmail, meetings, tesla, icloud): an empty inbox reported as "unreachable" because stderr was discarded where the empty status is printed; `splitlines()` splitting on a CR inside an escaped iCalendar field; 503 on a failed 2FA push treated as failed sign-in; `workflow_dispatch` runs ignored because the filter was `event=push`; a partial API response overwriting the last good reading with zeros; Chromium ignoring `image/jpeg` on paste so clipboard images must be PNG.

### 1.2 Omarchy/Quickshell-specific gotchas (each is a concrete rule for the reviewer)
- **`Color` must be read as `Commons.Color` on Qt >= 6.12** (`import qs.Commons as Commons`). An unqualified `Color.foreground` is a load-time-silent bug: the plugin loads and paints black.
- **`iconComponent` is scaled to a single bar icon (shell of 2026-10-13).** Multi-glyph content (count badges, countdown text) must be the button's own content with `hasVisualContent: true`.
- **Bar tooltips and any `Text` fed by another process are rich text.** Use `textFormat: Text.PlainText` or the plugin's `plain()` helper before assigning `tooltipText`, workspace names, camera names, notification bodies. Markup like `<img src=...>` makes the shell fetch URLs.
- **Plugins only see their own targets.** Forwarding a bar click to another plugin's widget cannot work (downloads 3bc21ae); the bar tracks popout state by the owner/coordinator key, not the popup instance (downloads 3995bb4).
- **A singleton from another file may not be ready when a delegate binds** (`store.iconFor`); guard with `store && typeof store.iconFor === "function"`.
- **Per-monitor widgets must read their own screen's workspace**, not the global focused workspace; windows opened by a shared coordinator must be told the output explicitly on Hyprland.
- **Secrets never go in argv** (`/proc/PID/cmdline` is mode 444). The environment is not much better (`/proc/PID/environ` is readable by every process of the same account and the watcher runs for days). Hand secrets over a pipe: `curl -K -`/`-H @-`, `jq --rawfile`, python reading fd 0; use process substitution (a here-string is backed by a temporary file) and switch `set -x` off before the `exec`, because bash traces the whole redirection first.
- **Cache/state under `$XDG_STATE_HOME`/`$XDG_CACHE_HOME`, mode 700, files 600, created with `umask 077`**, written via `mktemp` in that directory + `mv`, opened by file descriptor (return the bytes, not a name, from a validating helper), and swept on read as well as on save because an older install may have left bad modes or planted symlinks.
- **Bound everything another process hands you, in bytes and in seconds**: `curl --max-time --max-filesize`, `head -c`, `resp.read(N)` then check, a deadline around `Process`, and pass big JSON to `jq` on stdin (argv is limited to 128 KiB per argument, `Argument list too long`). A folder model must be capped before it enumerates, not after.
- **Never `-k`; pin the certificate and show the fingerprint before pinning; keep https through redirects** (Python's `urlopen` follows https -> http); install with `pip --require-hashes`/pinned digest.
- **Bash evaluates `a[$(cmd)]` inside `$(( ))` and `[[ -gt ]]`**: validate numbers from JSON/HTTP with a digits-only check before arithmetic.
- **Put `--` before an externally supplied URL/path** passed to `mpv`, `xdg-open`, `ffprobe`.
- **A helper run under `set -e` dies on the first half-written file** (`ffprobe` on an incomplete download); suppress/handle per item.
- **A child started by the app dies with the app** (`wl-copy`, a terminal); detach it (`setsid`/`Quickshell.execDetached`) when it must outlive the shell.
- **Multi-account/multi-instance state needs an instance-scoped directory** (`GOOGLE_WORKSPACE_CLI_CONFIG_DIR` per mailbox), otherwise one widget reads another's mail.

### 1.3 How his fixes are shaped
- One defect per commit, almost always 1-2 files and a median of a few dozen changed lines; the diff removes the one construct and adds the guard next to it. About a quarter also bump the manifest patch version (every compat fix does), about a quarter touch the README (he documents the new behaviour or the security reason).
- The subject states the **effect**, not the bug ("Hand the watcher its key on a pipe, not in its environment", "Keep the server count readable on the new Omarchy shell"); the body gives cause, trigger and how he verified it ("verified both ways, the key arrives and is absent from /proc/self/environ").
- Guard shapes seen repeatedly: caps (`head -c`, `read(N)`, folder-count ceiling), deadlines (`--max-time`, `timeout`, process watchdog), stdin/pipe for secrets, private state dirs with `umask 077` and open-by-fd, numeric validators (`number_or`), `--` terminators, `textFormat: Text.PlainText`, null/undefined guards on first paint, `exec` instead of command substitution, explicit instance directories, reset-on-reuse of Process flags, compat shims that qualify a type (`Commons.Color`).
- Hardening arrives in **chains**: argv -> environment -> pipe for the same Protect key (unifi 6d99719 then ed5835a); check mode of the cache directory -> sweep leftover files and planted symlinks (gmail 3fa16da, text-transform f2683d4 -> 275788c); validate then return the path -> return the bytes (github-build-monitor 78f1df4 after a9e537c); JPEG -> PNG -> JPEG -> PNG clipboard copy (icloud 8f9a71f, b4c0034, 09b0e12, a revert of the middle step); ulimit guard -> the trampoline symlink escaping the isolated home (text-transform bab270e -> f25c208). Reviewer implication: after any fix of this class, look one level down (same data, next channel) before approving.
- Version-compat fixes are swept across all repos within hours with identical commits; reviewing one plugin for them is enough to predict the same bug in all of his others.

### 1.4 What our Checker would and would not have caught (pre-fix code, see section 4)
- On the pre-fix trees the existing Checker (v2 and v3-fixes) credits only a handful of the real defects with a right-reason finding at the defect line (the `-k` TLS bypass, the unbounded `response.read()`, the unpinned `pip install`); `v3-fixes` @763fe65 and `checker-rules-v2` produced identical findings. Rules that fire near the line for another reason (USB-H01 curl size cap on a line that actually leaks a key in argv) are listed as COINCIDENT and not credited.
- Misses by class: secrets in argv inside `-H "X-API-KEY: $KEY"` and `jq --arg` (the existing "secret in argv" rule does not see header/`--arg` forms); secrets exported into the environment; bash arithmetic over external values; option injection without `--`; `Color` shadowing and `iconComponent` scaling (version contract, no rule); tooltip rich text; check-then-open races; all logic/state/layout bugs.
- The nine candidate rules USB-JV01..JV09 (`scripts/jv_rules.py`) cover the argv/env/arithmetic/option/redirect/tooltip forms and the two version contracts with no fire on HEAD of his hardened repos for JV01, JV03, JV04, JV05, JV07 and JV09, and a few known false fires on HEAD (JV02: a `--arg t "$token"` that carries a Gmail page token; JV08: two panels whose `iconComponent` text is a deliberate glyph) listed in `data/jv_rules_metrics.json`; JV07 (unqualified `Color.`) fires on most older plugins by design (they break on Qt >= 6.12) and must stay experimental until the target Omarchy version is known.

### 1.5 Prompt guidance that follows
Add to the reviewer prompt (group A, load = "broken"): (a) an unqualified `Color.` singleton next to `import qs.Commons` on a Qt 6.12 shell (read it as `Commons.Color`); (b) `iconComponent` carrying text/badges on the current shell (must be the button's own content with `hasVisualContent: true`); (c) a `Text`/`tooltipText` bound to data from another process without `Text.PlainText` (group B already lists rich text; add tooltips explicitly). Add to group B: secrets in argv *including curl `-H` and `jq --arg`*, secrets in `export`ed environment of a long-lived process, `$(( ))`/`[[ -gt ]]` over external values, `--` missing before an external URL, `urlopen` following redirects from https, check-then-open on a cache path. Keep tier B (cosmetic/UX polish: alignment, label wording, polling cadence) out of blockers: in this history they are about a quarter of the fixes and have no line a reviewer could defend as a defect on its own. Tell the model to cite the statement that actually leaks or fails (the `curl` line, the binding), not the declaration that sets it up, and to look for a second hop after a fix (argv -> env -> pipe).
