# Usuba Checker scripts

The Usuba Checker decides whether an [Omarchy](https://omarchy.org) shell plugin actually works. It is **plain Python, not AI**: deterministic static checks plus a real headless run of the plugin inside a reference Omarchy 4.0.4 / Quickshell environment. The same plugin always gets the same verdict.

Every failure carries a rule id from the Usuba Standard ([`functest/STANDARD.md`](functest/STANDARD.md)), so a report can be read by a person or handed to a reviewer model.

## Run it

```sh
python3 functest/functest.py <plugin dir>             # full JSON report
python3 functest/functest.py <plugin dir> --reasons   # PASS/FAIL plus one line per rule hit
```

Python 3.10+ with the standard library only. The runtime stage needs `quickshell` (and `qmllint` for some checks) on `PATH`; without them the static checks still run and the runtime stage reports why it could not start.

## Layout

| Path | What it is |
|---|---|
| `functest/functest.py` | Entry point: static checks + runtime, combined into one verdict |
| `functest/static_checks.py` | Manifest, file layout, and QML/JS static checks |
| `functest/dell_checks.py` | Static checks derived from a real Omarchy 4.0.4 install |
| `functest/runtime.py` | Headless Quickshell run of the plugin against the reference shell |
| `functest/usuba/` | Usuba hardening: `checks.py`, `rules.py` (single source of truth for rule ids), `types.json` (QML type table) and `build_types.py` |
| `functest/STANDARD.md` | The Usuba Standard, generated by `cd functest && python3 -m usuba.rules > STANDARD.md` |
| `functest/dell_env/` | Builds the headless environment: stub binaries, fake `hyprctl`, the probe IPC function, and the Omarchy shell snapshot |
| `functest/fixtures/hyprland-0.56.2/` | Captured `hyprctl` output the fake `hyprctl` replays |
| `dell-ref/omarchy-4.0.4/` | `/usr/share/omarchy` from Omarchy 4.0.4-1 (images excluded), used as the full reference tree |
| `validator/` | Earlier standalone plugin validator (`omarchy-plugin-validate`, qmllint wrapper) |
| `tests/` | Checker tests: `python3 -m unittest discover -s tests` |

Environment overrides: `FT_DELL_FULL` points the runtime at a different Omarchy tree.
